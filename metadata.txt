about=02Agent OSM Downloader is an alpha QGIS 3.28+ and QGIS 4 acquisition studio for OpenStreetMap. Its 15 thematic groups and 30 curated presets cover urban context, street and rail networks, morphology, buildings, land use, green-blue systems, public transport, religion, tourism, heritage, sport, cycling, cars, traffic, healthcare, education, emergency services and administrative places. Urban Context connects street network, built form, trees, public transport and public-realm datasets. Datasets within a theme can be combined in one bounded request. The English Command panel resolves dataset requests and named administrative places through pinned Overpass mirrors. A standard OpenStreetMap XYZ basemap can be added from the dock, and downloaded line layers can use OSM highway categories for distinct widths or one uniform width. A structured advanced-query panel combines up to four validated OSM tags with ANY or ALL matching, selectable geometry scope, examples, key/value suggestions and a read-only Overpass preview. Sixteen persistent map styles provide live palette previews and native categorized QGIS renderers for building function, highway hierarchy, rail, transit routes, water, green space, trees and common points of interest. Users can also request one bounded custom OSM key/value tag. Agent Protocol v1 exposes four stable QGIS Processing endpoints that SmartModeler GIS discovers, inspects and runs only after a validated proposal and explicit Run approval. The dock shows the active SmartModeler AI provider/profile and opens its shared AI Connections and Agent Workspace interfaces; API keys remain in SmartModeler's process memory or encrypted QGIS vault and are never copied into this plugin. Downloads use the current map or active-layer extent, three pinned Overpass mirrors with diagnostic failover, strict area/response/feature limits, cancellation, session caching and temporary point/line/polygon outputs. The plugin accepts no editable raw Overpass query, arbitrary URL, user path, API key or pip dependency. Online User Manual & Documentation: https://yusufeminoglu.github.io/02Agent-OSM-Downloader/ | If you find this plugin helpful, please consider starring the repository on GitHub (https://github.com/YusufEminoglu/02Agent-OSM-Downloader)!
