about=02Agent OSM Downloader is a focused QGIS 4 data-acquisition studio for OpenStreetMap. It offers curated thematic presets for networks, morphology, green-blue systems, public transport, religious sites, tourism, sport, cycling, cars, traffic, healthcare, education and emergency services; a custom key/value downloader; an offline natural-language intent router; and Processing algorithms that SmartModeler GIS Agent can inspect and run. Requests use the current map or active-layer extent, three pinned Overpass mirrors, strict area/response/feature limits, cancellation, a session cache and temporary QGIS outputs. Raw Overpass queries, arbitrary URLs, user paths, API keys and pip dependencies are not accepted.
