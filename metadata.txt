about=02Agent OSM Downloader is an AI-agent-ready QGIS 4 acquisition studio for OpenStreetMap. Its 13 thematic groups and 26 curated presets cover street and rail networks, morphology, buildings, land use, green-blue systems, public transport, religion, tourism, heritage, sport, cycling, cars, traffic, healthcare, education and emergency services. Users can also request a bounded custom OSM key/value tag or type a Turkish/English command into the offline intent router. Agent Protocol v1 exposes two stable QGIS Processing endpoints that SmartModeler GIS discovers, inspects and runs only after a validated proposal and explicit Run approval. The dock shows the active SmartModeler AI provider/profile and opens its shared AI Connections and Agent Workspace interfaces; API keys remain in SmartModeler's process memory or encrypted QGIS vault and are never copied into this plugin. Downloads use the current map or active-layer extent, three pinned Overpass mirrors, strict area/response/feature limits, cancellation, session caching and temporary point/line/polygon outputs. The plugin accepts no raw Overpass query, arbitrary URL, user path, API key or pip dependency.
