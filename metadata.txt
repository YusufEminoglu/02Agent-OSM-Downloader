about=
    02Agent OSM Downloader gets OpenStreetMap data into QGIS for the area you care about and styles it on arrival. Pick a ready dataset (roads, buildings, parks, schools, bus stops, hospitals and many more), choose where - the map view, a place name with its real boundary, the features you selected, a rectangle you draw, or a radius around a point - and press Download. Keep the result as temporary layers or save it straight into a GeoPackage with its style inside, so the file opens styled anywhere; every layer carries the OpenStreetMap attribution and the date of the data. Recent downloads can be run again with today's data in one click, and the Command tab understands short English or Turkish requests such as "download parks in Konak" or "Konak'taki parkları indir". It is a stable QGIS 3.28+ and QGIS 4 plugin: its 16 thematic groups and 43 curated presets cover scale-aware OSM as-is stacks, urban context, street and rail networks, morphology, buildings, land use, green-blue systems, public transport, religion, tourism, heritage, sport, cycling, cars, traffic, healthcare, education, emergency services and real OSM admin-level places, and datasets within or across themes can be combined in one bounded request.
    The four-tab dock provides Presets, Query, Command and Agent workflows. Place names are resolved by the OpenStreetMap Nominatim geocoder, which lists every match with its address context and administrative level; when the chosen place has a mapped boundary the download follows that boundary instead of a rectangle across Presets, Custom tag and Advanced Query workflows, so a district stops at the district edge. An extent wider than one bounded request is split into a grid of tiled requests, downloaded in sequence and merged so an object crossing a tile seam stays one feature, letting a single job cover up to 2,500 square kilometres. A live estimate above the Download button reports the request area and how many requests it needs. A standard OpenStreetMap XYZ basemap can be added from the dock, while downloaded line layers can use OSM highway categories for distinct widths or one uniform width. The structured advanced-query panel combines up to six validated OSM tags with ANY or ALL matching, an optional regex (~) value mode, an optional exclude tag applied after the response arrives, selectable geometry scope, examples, key/value suggestions and a read-only Overpass preview. Every Processing endpoint accepts optional AREA_ID boundary clipping and optional exclude tags. Overpass responses persist in an on-disk cache with a one-click Clear cache action, and a transient mirror error gets one retry before moving to the next pinned mirror.
    The offline Command tab tolerates small misspellings, recognises "without X" to exclude a tag, and can combine multiple datasets across or within themes when a command names more than one (for example "buildings and parks in Konak"). Commands are interpreted entirely on this computer; only a resolved place name is ever sent out.
    Seventeen persistent map styles provide live palette previews, live restyling of active 02Agent project layers, and native categorized QGIS renderers for buildings, roads, rail, transit, water, green space, trees, administrative places and common points of interest. Agent Protocol v1 exposes four stable QGIS Processing endpoints that 02Agent Smart Modeler can discover, inspect and run only after a validated proposal and explicit user approval. API keys remain in 02Agent Smart Modeler's process memory or encrypted QGIS vault and are never copied into this plugin.
    Downloads use the current map extent, the active-layer extent, the selected features, a drawn rectangle, a radius of 50 m to 5 km around a point, or a geocoded place; three pinned Overpass mirrors with diagnostic failover, strict area, request, response and feature limits, cancellation, a persistent cache and a confirmation before a large unfiltered pull. Only four fixed hosts are ever contacted: the three Overpass mirrors and the Nominatim geocoder. The plugin accepts no editable raw Overpass query, arbitrary URL, API key or pip dependency. Illustrated task guides and the full manual: https://geophilo.com/zero2agent_osm_downloader/
